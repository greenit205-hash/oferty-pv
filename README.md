# Oferty PV – Smart Energy

Generator ofert na instalacje fotowoltaiczne i magazyny energii z eksportem do PDF.

- Dwa rodzaje ofert: nowa instalacja PV (opcjonalnie z magazynem) oraz magazyn energii do istniejącej instalacji (z wymianą falownika).
- Automatyczne liczenie mocy, pojemności, produkcji, netto/brutto/VAT i kwoty po dofinansowaniu.
- Biblioteka kart katalogowych (moduły, falownik, magazyn, EMS, inne) doklejanych na końcu PDF.
- Oferty, dane firmy i karty zapisują się lokalnie w przeglądarce (nic nie trafia na serwer).

Uruchomienie: otwórz `index.html` w Chrome albo włącz GitHub Pages dla tego repozytorium.
